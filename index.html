User Agent Parser

Break a UA string into its parts

Paste a User-Agent string, or load the one your browser is sending, and see the browser, rendering engine, operating system, and device type it points to. Parsing is done with local heuristics on this page. No library, no network.

All parsing happens locally. The string is never sent to any server.
